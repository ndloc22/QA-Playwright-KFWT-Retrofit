## 📝 Description

As  operation technican ("Betrieb") (new role) I want to document the primary and secondary commissioning status of a station in a dedicated process task so that the completion of the primary commissioning is recorded and verified before the process continues to EAM update.
Acceptance criteria: 

	A new task is introduced after the task "Configure updated technical Type (UI) named "Primäre und Sekundäre Inbetriebnahme".
	The Task has the full view so all fields for the station are visible but not editable
	The task can be skipped so it needs to be added to configuration tab Workflow Administration
	New field should be added at the bottom in a data card called "Primary and secondary commissioning" / "Primäre und Sekundäre IBN"
	
		Checkbox "Primary commissioning done" / "Primärtechnisch in Betrieb genommen", default unchecked 
		Checkbox "Secondary commissioning done" / "Sekundärtechnisch in Betrieb genommen", default unchecked
		Date field labelled "Primary commissioning date" /" / "Datum der primärtechnischen Inbetriebnahme" (optional)
		Date field labelled "Secondary commissioning date" / "Datum der sekundärtechnischen Inbetriebnahme" (optional)
		Comment field with labelled "Comment commissioning" / "Kommentar Inbetriebnahme" (optional)
	
	
	Task can only be completed when checkbox "Primary commissioning done" and "Secondary commissioning done" is checked.
	After completing the task, the process shall continue with the next step "Update eIOT".  
	Primary and secondary done and date shall also be updateable via endpoint status name: PRIMARY_SECONDARY_COMMISSIONING . 
	After Primary commissioning has been done, EAM shall be updated as there might be some weeks between primary and secondary commissioning. 
	This process step must be skippable
	Add status to search telecontrol device
	For retrofit the first taks + EAM Update will be skipped as the primary commissioning does not change. The primary com checkbox is checked, date is empty. Primary commissioning date + checkbox is not updated in EAM only secondary commissioning date and checkbox



Implementation hint: 

	most of the time the tasks will be completed via endpoint
	only digiONS + retrofit 
	have two tasks but with the option to skip the second task if all commissioning data is provided
	first task: 
	
		Name: "Primäre Inbetriebnahme" / "Primary Commissioning"
		primary com + date are mandatory
	
	
	EAM Update
	second task: 
	
		Name: "Sekundäre Inbetriebnahme" / "Secondary Commissioning"
		primary com + date are disabled but shown 
		secondary com + date are mandatory
