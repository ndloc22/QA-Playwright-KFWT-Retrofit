# \(17\.3\) E\-Mail Notification about multiple EQUIs of the same objecttype

## General

|  |  |
| --- | --- |
| **User Story** | As data and structure maintainer, I need an information, if through the EAM interface multiple EQUIs for the same objecttype were detected. |
| **JIRA** |  |
| **Description** | In the last step of the DigiONS / Retrofit process, the necessary information is transferred to the EAM system (<https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247612/17+Transfer+to+EAM>).During the execution of the interface, different use cases are possible. One of them is, that for an objecttype multiple EQUIs are detected and it's not clear, which one has to be updated. In this case, an Admin Retry Task will be created (KFWT-). In addition the data and structure maintainance team needs to be informed about this issue of multiple EQUIs.Also here, if this issue happens for more than one objecttype of the same telecontrol device, the e-mail should provide a summary of the affected objecttypes & equipment numbers. |
| **Preconditions** | <https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247612/17+Transfer+to+EAM> with appearance of several EQUIs of the same object type |
| **State** | IN REFINEMENT |
