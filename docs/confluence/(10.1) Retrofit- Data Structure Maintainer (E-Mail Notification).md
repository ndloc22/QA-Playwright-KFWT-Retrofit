# \(10\.1\) Retrofit: Data Structure Maintainer \(E\-Mail Notification\)

  

## General

|  |  |
| --- | --- |
| **User Story** | As Product Owner I want that the data and structure maintainer is informed via email that the TP structure in the EAM needs to be expanded with new equipments. Without this trigger, the equipment will be missing in EAM. Without the equipment, there are no fieldsets in EAM to which the collected data from process can be transferred to. |
| **JIRA** |  |
| **Description** | Relevant in the Retrofit process, when a retrofit was picked by a Planer and all necessary information were added. |
| **Permission** | Role Planer DigiONS |
| **Preconditions** | <https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247145/10+Add+additional+information> for digiONS Type Retrofit (LM, LO, SM, SO) |
| **State** | FINAL |
