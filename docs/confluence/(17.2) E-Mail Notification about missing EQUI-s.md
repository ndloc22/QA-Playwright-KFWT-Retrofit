# \(17\.2\) E\-Mail Notification about missing EQUI/s

## General

|  |  |
| --- | --- |
| **User Story** | As data and structure maintainer, I need an information, if through the EAM interface an additional EQUI was created for a technical place. |
| **JIRA** |  |
| **Description** | In the last step of the DigiONS / Retrofit process, the necessary information is transferred to the EAM system (<https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247612/17+Transfer+to+EAM>).During the execution of the interface, different use cases are possible. One of them is, that an EQUI for some of the to be updated attrbutes is not available / not created yet. In this case, the EQUI should be created and the data and structure maintainance team should receive an info mail about the creation.If multiple EQUIs are created, when transferring the device to EAM, all affected EQUIs / objecttypes should be listed in one mail. |
| **Preconditions** | <https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247612/17+Transfer+to+EAM> with creation of one or more EQUIs |
| **State** | IN REFINEMENT |
