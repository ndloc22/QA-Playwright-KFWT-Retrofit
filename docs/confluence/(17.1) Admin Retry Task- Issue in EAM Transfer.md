# \(17\.1\) Admin Retry Task: Issue in EAM Transfer

## General

|  |  |
| --- | --- |
| **User Story** | As an Admin I want to receive an information, if the EAM transfer failed with information about the affected technical place and also an indication, what was going wrong. |
| **JIRA** |  |
| **Description** | In the last step of the DigiONS / Retrofit process, the necessary information is transferred to the EAM system (<https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247612/17+Transfer+to+EAM>).If an issue occurs in this step, a Admin task to handle a cancelled EAM transfer is necessary. |
| **Permissions** | KFWG Admin |
| **Preconditions** | <https://confluence.agile.eon.com/wiki/spaces/kfwt22/pages/880247612/17+Transfer+to+EAM> with an issue in the transfer |
| **State** | IN REFINEMENT |
